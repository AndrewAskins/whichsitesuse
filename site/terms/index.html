// 07  The data

The data and its limits

The technology data comes from HTTP Archive's public monthly crawl, detected with its fork of the open-source Wappalyzer rules, and the Core Web Vitals come from the Chrome UX Report. We don't crawl sites ourselves. The crawl runs monthly, so results can be up to about six weeks old, sites with little Chrome traffic are often missing, and tools that don't load on public pages can't be detected. Detection rules can also be wrong.

The data is provided as is. We don't promise it's accurate, complete or current, and you shouldn't rely on it alone for decisions where a mistake would be costly. Every response includes an attribution line for HTTP Archive and the Chrome UX Report, and you should keep it when you publish results.
