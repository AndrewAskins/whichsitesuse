Salesforce, November 2026 crawl

Companies using Salesforce

To find companies using Salesforce, look for the Salesforce products that load on their websites, such as Commerce Cloud stores, Service Cloud chat and Pardot tracking. The core CRM runs behind a login and leaves no trace, so this page lists the products HTTP Archive's November 2026 crawl can see and the search that finds every site running any of them, at one credit per site after a free count.

// 01  The count

How many websites show Salesforce?

Counted on mobile homepages in HTTP Archive's November 2026 crawl of 15,269,451 sites.

Whatever the total, it counts websites where a Salesforce product loaded something the crawler could see. It isn't a count of Salesforce customers, and it will be well below Salesforce's own figures, because most of what Salesforce sells runs behind a login.

Two more entries imply Salesforce without carrying its name: an ApexPages response header, and a WordPress web-to-lead plugin that sends form entries to Salesforce. Because only some entries imply the parent, a search for salesforce alone misses sites whose only trace is Pardot, Marketing Cloud or one of the personalization products. Search for any of the eight slugs when you want them all, and check the slugs with find_technologies, which is free.

Sales Cloud itself runs behind a login, so a company that uses Salesforce as its CRM and nothing on its website looks like any other site to the crawler. The crawl also only loads the mobile homepage and one inner page, so a chat widget or tracking tag that appears only on a support or pricing page can be missed, and sites with little Chrome traffic are often not in the crawl at all.

// 03  The search

Count the Salesforce sites, then pull the list

The counts are free. The last call spends credits and stops at max_credits.

# Any site showing any Salesforce product
count_sites  {"technologies": ["salesforce", "salesforce-commerce-cloud",
                "salesforce-service-cloud",
                "salesforce-marketing-cloud-account-engagement",
                "salesforce-marketing-cloud-email-studio",
                "salesforce-interaction-studio",
                "salesforce-audience-studio", "salesforce-desk"],
              "match": "any"}

# Commerce Cloud stores in the top 100k that fail LCP
search_sites {"technologies": ["salesforce-commerce-cloud"], "max_rank": 100000,
              "cwv": {"lcp": "fail"}, "limit": 500, "max_credits": 500}

# The same search over REST
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.whichsitesuse.com/v1/sites?technologies=salesforce-commerce-cloud&max_rank=100000&cwv=lcp:fail&limit=500&max_credits=500"

Results come best-ranked first, up to 1,000 per call, with next_cursor for the next page. Each result lists which of your technologies matched, so an any-match list shows which Salesforce product each site runs.

// 07  Questions

Common questions

Can you detect Salesforce CRM from a website?

Mostly not. Sales Cloud runs behind a login, so it leaves no trace on a company's public pages. What can be detected are the Salesforce products that load scripts, cookies or headers on the site itself, such as Commerce Cloud, Service Cloud chat and Pardot tracking.

How do I search every Salesforce product at once?

Pass all the Salesforce slugs to count_sites or search_sites with match set to "any". A site that runs at least one of them is included.

Do I get contacts at these companies?

No. Results are domains with the Salesforce products found on them, a popularity bucket and Core Web Vitals. There is no contact or firmographic data.

Can I see which Salesforce product a site runs?

Yes. Each result lists the technologies from your search that matched, so an any-match search shows which Salesforce entries were found on each site.
