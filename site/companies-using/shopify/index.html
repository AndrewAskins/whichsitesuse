// 02  Detection

How Shopify is detected, and what slips through

From the Shopify entry in HTTP Archive's Wappalyzer rules (checked November 2026).

A store is counted when the crawler sees one of Shopify's own signals: the _shopify_s or _shopify_y cookies, a powered-by: Shopify or x-shopify-stage response header, Shopify's checkout and digital-wallet meta tags, JavaScript objects such as ShopifyAPI or SHOPIFY_API_BASE_URL, or requests to a myshopify.com address. Links to cdn.shopify.com also count, at lower confidence. On top of that, 104 Shopify app and framework entries imply Shopify, so a store whose app scripts are visible is counted even if the core signals are hidden.

Stores built on Shopify's Hydrogen framework are counted when they send Hydrogen's powered-by header. A custom headless front end that loads none of these signals on the crawled pages can be missed. There's no separate Shopify Plus entry, so Plus and standard stores can't be told apart, and Shop Pay is its own entry (shop-pay) if you want stores that show it.

Here's what one result looks like. In the November 2026 crawl, allbirds.com had 29 technologies detected on its mobile homepage, Shopify and Shop Pay among them, sat in the top 500k bucket and passed all three Core Web Vitals in October 2026 field data (LCP 1.9 s, INP 175 ms, CLS 0).

From a free count to a filtered list

The counts are free. The last call spends credits and stops at max_credits.

# All Shopify stores, split by popularity bucket
count_sites  {"technologies": ["shopify"]}

# UK stores in the top 100k
count_sites  {"technologies": ["shopify"], "max_rank": 100000, "tld": ["co.uk"]}

# Pull them, capped at 2,000 credits
search_sites {"technologies": ["shopify"], "max_rank": 100000, "tld": ["co.uk"],
              "limit": 1000, "max_credits": 2000}

# The same search over REST
curl -H "Authorization: Bearer YOUR_API_KEY" \
  "https://api.whichsitesuse.com/v1/sites?technologies=shopify&max_rank=100000&tld=co.uk&limit=1000&max_credits=2000"

Results come best-ranked first, up to 1,000 per call, with next_cursor for the next page. Add exclude_technologies to drop stores that already run an app you compete with, and confirm any slug with find_technologies, which is free.

// 07  Questions

Common questions

Why is this lower than other Shopify store totals?

The crawl only includes sites with real Chrome traffic, so stores with almost no visitors aren't in it, and each of the 756,868 is a domain people actually visit. Totals that try to count every store ever opened will be higher.

Can I get Shopify stores in one country?

You can filter by TLD, such as co.uk or com.au. There is no country filter, so a store on a .com domain shows up under com wherever it sells.

Can I list only Shopify Plus stores?

No. The detection rules have no separate Shopify Plus entry, so Plus and standard stores look the same in the data.

Are headless Shopify stores included?

Stores on Shopify's Hydrogen framework are detected when they send Hydrogen's powered-by header. A custom headless front end that loads none of Shopify's cookies, headers or scripts on the crawled pages can be missed.
